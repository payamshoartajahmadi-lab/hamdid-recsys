# مستندات مأموریت هم‌دید

مأموریت فعلی **HD-01، فاز ۰۱** است: ایجاد بستهٔ پایتون قابل نصب و قابل بررسی در محیط تازه، همراه با تست CLI و کنترل‌های CI. داده، مدل و قابلیت‌های فازهای بعد در این مأموریت اجرا نمی‌شوند.

## سند موجود

- [فاز ۰۱: پایهٔ پایتون و کنترل کیفیت](phases/01-foundation.md)؛ کپی بدون تغییر سند تحویل‌شدهٔ `01-foundation.md`، نسخهٔ کارآموزی 1.1.
- [گزارش اجرای محلی](verification.md)؛ نتایج واقعی نصب، تست و بررسی workflow و محدودیت‌های تحویل GitHub.

## اسناد تحویل‌نشده

قرارداد فاز ۰۱ وجود شرح مأموریت و هفت سند بستهٔ کارآموزی را می‌خواهد. تنها فایل فاز ۰۱ تحویل شده است؛ مجموعهٔ کامل هنوز ثبت نشده و این الزام برای تحویل نهایی **BLOCKED** است.

سند موجود به `docs/phases/00-roadmap.md` و `docs/INTERN-BRIEF.md` ارجاع می‌دهد، اما اصل این دو فایل در دسترس نیست. نام و محتوای باقی اسناد بسته نیز باید از نسخهٔ رسمی سرپرست دریافت شود. این نمایه و توضیح مأموریت بالا جایگزین اصل راهنمای کارآموز یا نقشهٔ راه نیستند. نام و محتوای اسناد مفقود ساخته نشده و نسخهٔ قدیمی مخصوص Codex یا ZIP تحویل وارد مخزن نشده است.

پس از دریافت مجموعهٔ رسمی، فایل‌ها باید در مسیرهای اصلی خود ثبت و ارجاع‌های نسبی سند فاز ۰۱ بررسی شوند. وجود اسناد فازهای بعد فقط به معنی ثبت قرارداد است و مجوز پیاده‌سازی آن فازها نیست.
